# TitanLabs
Tienda web e-commerce desarrollada con React + Vite.

## Tecnologías usadas
- React
- Vite
- CSS
- JavaScript
- GitHub

## Funciones
- Página principal
- Catálogo de productos
- Carrito de compras
- Página de checkout
- Botón para volver al inicio
